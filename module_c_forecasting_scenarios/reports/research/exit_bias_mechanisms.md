# Exit survey bias — mechanisms (hypotheses only)

This note lists **modeling hypotheses** for the exit / quick-count bias stage. It does not assert proven misconduct.

- Differential turnout vs sampling frame
- Social desirability response patterns
- Timing of release relative to voting window (see OEA/EU metadata stub)
- Frame mismatch vs certified preference aggregation
