# Battleground reference data (σ_idio estimation)

Evidence inputs for `c_battleground_v0.5` per-department idiosyncratic dispersion
(`module_c_forecasting_scenarios/geo/sigma_estimator.py`).

## Files

| File | Purpose |
|---|---|
| `dept_poll_margins.csv` | Subnational pre-election poll margins (2013, 2018) |
| `tsje_2013_department_results.csv` | TSJE 2013 presidential results by department |
| `battleground_sigma_idio.yaml` | Generated by pipeline — per-dept σ estimates |

2018 TSJE results ship as package data:
`module_c_forecasting_scenarios/src/.../geo/tsje_2018_department_results.csv`.

## Schemas

### `dept_poll_margins.csv`

```
department_ascii,election_year,poll_date,margin_pp_poll,candidate_a_name,candidate_b_name,pollster_id,sample_size,source,source_url,notes
```

- `margin_pp_poll`: Candidate A minus B, percentage points (positive = ANR/Colorado side).
- Row weights for estimation derive from `notes` (direct=1.0, regional_breakdown_only=0.5,
  regional_proxy=0.25).

### `tsje_YYYY_department_results.csv`

Same columns as the 2018 package CSV. Column 3/4 map ANR-side vs opposition candidate
(Cartes/Alegre 2013; Abdo/Alegre 2018).

## Provenance

- **2013 TSJE:** Portal Guaraní reproduction citing TSJE final 2013 totals
  (Cartes 1,104,169 / Alegre 889,451). National sum gate enforced on ingest.
- **Polls:** GRAU & Asociados (Última Hora 2013-04-14, 2018-04-10); ATI Snead (Infobae 2018-04-19).

## Departments without poll rows

Caaguazu, Presidente Hayes, Boqueron, Alto Paraguay, Exterior — σ from 2013↔2018
election cross-section fallback only.
